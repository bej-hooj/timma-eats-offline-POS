Borne — the defines are mandatory, a build without them cannot sell:

```
flutter build apk --release \
  --dart-define=SUPABASE_URL="$SUPABASE_URL" \
  --dart-define=SUPABASE_ANON_KEY="$SUPABASE_ANON_KEY" \
  --dart-define=KIOSK_DEVICE_KEY=<see docs/setup-config.md, gitignored> \
  --dart-define=KIOSK_MANAGER_PIN=2468 \
  --dart-define=KIOSK_DEV_BRANCH_ID=10000000-0000-4000-8000-000000000001 \
  --dart-define=KIOSK_DEV_DEVICE_ID=borne-gm92-imac-kimya \
  --dart-define=KIOSK_DEV_LABEL="Borne"
```

`SUPABASE_URL` / `SUPABASE_ANON_KEY` come from
`~/Desktop/Timma-eats/Supabase.txt`, lines 5 and 8.

⚠ Use a DIFFERENT `KIOSK_DEV_DEVICE_ID` per till. Two tills sharing one id
share a ticket sequence and print the same 4-character code twice. The Samsung
test build uses `borne-samsung-test`.

⚠ Version is `1.0.0+2011`. It must stay **above 2010**: a Samsung still
carried versionCode 2010 from an August build and anything lower is refused
with `INSTALL_FAILED_VERSION_DOWNGRADE`.

## 6 · Hard-won facts from today — do not rediscover these

- **Measure on the device, do not reason.** The kitchen card was capped at
  `maxHeight = 153 dp` (the lane's visible height on a 411 dp-tall screen) and
  silently dropped the ticket code, the dishes and the total. The data was
  fine (`lines=1 total=5100 label=01`); a debug build and one `debugPrint`
  found it in two minutes after an hour of guessing.
- **"No overflow" is not "readable".** Every responsive test passed through
  that entire defect. The sweeps now assert the DISH is on the card.
- **Scale layout thresholds by the text scale.** The kitchen Samsung is at
  font scale 1.1 and the borne can be at 1.3. A threshold in raw dp made a
  lane heading truncate three times and pushed *Commander* off a basket.
- **A test that cannot fail is worse than none.** Two were written and deleted
  today after they passed with the fix removed.
- **Release builds strip `debugPrint`** — build `--debug` to diagnose on
  hardware.
- `flutter_test` substitutes a full-em font, so glyph widths measured in the
  harness are meaningless; assert shapes (aspect ratio, line height, which
  layout branch) instead.
- The borne shows a **system firmware update prompt** ("GM92V2… 22.68 MB").
  It was cancelled. Do not let it run during service.
