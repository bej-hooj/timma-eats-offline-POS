## Rules already paid for — do not rediscover

- A lane is presentation; a transition is a state-machine fact. `pending_payment`
  is settled, never advanced.
- The client never computes a price. min/max count DISTINCT options.
- The collection QR is an HMAC, not a ticket number. The pairing code never
  crosses the wire.
- `flutter_test` substitutes a **fixed-width font**: text widths and wrapping in
  a widget test are not the device's. Assert geometry in tests, legibility on
  hardware. Six real layout defects were found only on the device.
- `pos_core` and `pos_link` are pure Dart — `dart test`, not `flutter test`.
- Test in **French**, at real widths, on the real medium.
- Never `adb shell svc wifi disable` on the Samsung: adb rides that radio.
- Fix every defect found in the same pass. Commit and push as you go.
