## Rules already paid for — do not rediscover

- **A fixture must never outrank real data.** The seeded menu stamped itself
  with the current epoch while the server's version is the epoch of the last
  dashboard edit — always in the past — so every real fetch was a
  `snapshot_downgrade` and a tablet that had once run a seeded build could never
  accept the real menu again. The seed is version `1` now.
- **Overrides a root-scoped provider must see belong in the ROOT scope.**
  Riverpod 3 does not re-instantiate a provider in a child scope just because it
  reads an overridden one.
- A lane is presentation; a transition is a state-machine fact.
- The client never computes a price. Integer XAF, engine-priced, snapshotted.
  min/max count DISTINCT options. Required choices are never skipped.
- The six-digit pairing code **never crosses the wire**.
- `flutter_test` substitutes a fixed-width font: assert **geometry** in tests,
  legibility on hardware. Measure the **column**, not the title — a title fits
  long after its column has run off the screen.
- `pos_core` / `pos_link` are pure Dart: `dart test`, not `flutter test`.
- Test in **French**, at real widths, on the real medium.
- Never leave a flaky test in the suite; record the gap instead.
